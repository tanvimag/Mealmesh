# MealMesh - Surplus Food Redistribution Network

DBMS Experiential Learning - Level 3 Project
PES University

## Problem Statement

MealMesh connects food providers such as restaurants, bakeries, grocers and event organizers with surplus edible food to nearby recipients such as NGOs, shelters and individuals.

Recipients can browse available food listings and claim them, helping reduce food waste.
